# Weapon Interaction Failure States

## Purpose

This document defines failure states for weapon interaction.

A failure state is an interaction-owned condition where a hand/contact/object/pose/action cannot continue as authored or predicted.

---

## Scope Boundary

This document covers failures inside weapon interaction:

```text
hand cannot reach target
contact quality is below threshold
weapon is unsupported
object alignment failed
socket or interaction point missing
moving part path invalid
mirroring broke presentation target
network correction invalidated prediction
pose cannot recover
```

It does not own external backend failures such as no ammo, damage rejection, projectile failure, inventory UI errors, camera failure, or locomotion speed constraints.

---

## Failure Classes

Recommended failure classes:

```text
AuthoringFailure
RuntimeReachFailure
ContactFailure
StabilityFailure
ObjectAlignmentFailure
MovingPartFailure
MirroringFailure
PredictionFailure
RecoveryFailure
ExternalDependencyFailure
```

---

## Authoring Failure

Authoring data is invalid.

Examples:

```text
missing MainGripSocket
missing MagazineWellSocket
zero-length LocalInsertAxis
sequence step references unknown interaction point
object profile missing InsertTipSocket
moving part references missing bone
```

Expected response:

```text
fail validation before runtime when possible
block runtime action if validation was bypassed
show exact missing/invalid authoring field
```

---

## Runtime Reach Failure

A hand cannot reach the target generated by the plan.

Examples:

```text
magazine target too far
support grip unreachable after pose offset
mirrored target outside arm range
elbow pole produces invalid arm pose
```

Expected response:

```text
try alternate allowed pose offset
try fallback pose
try soft failure visual recovery
reject or cancel interaction if no valid target exists
```

---

## Contact Failure

A required contact cannot be established or maintained.

Examples:

```text
main grip lost
support grip quality below threshold
shoulder contact cannot settle
object grip slips before insert
```

Expected response:

```text
enter Recovering if possible
restore contact target
fall back to safer pose
interrupt action if required contact remains lost
```

---

## Stability Failure

The weapon would become unsupported.

Examples:

```text
support hand released while main grip is not stable enough
stocked heavy weapon loses shoulder and support contact
reload plan releases wrong contact
```

Expected response:

```text
block current step
recover support/shoulder contact
choose alternate manipulation hand if authored
fallback to stable hold pose
```

---

## Object Alignment Failure

A reload/object visual cannot align to the weapon interaction point.

Examples:

```text
InsertTipSocket wrong
magazine rotated incorrectly
object path reaches well but lock alignment fails
mirrored object transform does not match mirrored well transform
```

Expected response:

```text
pause before commit
blend object to closest valid pre-insert pose
recover or reject before authoritative commit
show alignment error in debug/editor preview
```

---

## Moving Part Failure

A moving part cannot follow authored path.

Examples:

```text
bolt axis invalid
pump travel distance wrong
hand follow socket missing
moving part state conflicts with commit state
```

Expected response:

```text
block mechanism commit
return moving part to last valid visual state
recover hand to hold pose
report authored data error if deterministic
```

---

## Mirroring Failure

Mirrored presentation invalidates a target or axis.

Examples:

```text
target mirrored twice
object path not mirrored with hand path
axis semantic changed after mirroring
Control Rig mirrored targets again
```

Expected response:

```text
disable duplicate mirror stage
recompute presented targets from canonical data
fall back to canonical preview if editor-only
report mirror stage conflict
```

---

## Prediction Failure

Predicted interaction disagrees with authority.

Examples:

```text
predicted reload accepted locally but rejected by server
predicted object visual duplicated
predicted step index differs from authority
predicted pose state corrected
```

Expected response:

```text
remove predicted-only visuals
blend hands to authority targets
restore authoritative pose lifecycle
consume correction revision
```

---

## Recovery Failure

The system cannot restore a valid pose/contact/object state.

Examples:

```text
previous stable pose invalid
fallback pose unreachable
object state unknown
weapon component missing
```

Expected response:

```text
clear interaction targets
enter Failed or SafeHold state
show debug reason
wait for external owner to reset/equip/clear weapon if needed
```

---

## External Dependency Failure

An external system cannot provide required input.

Examples:

```text
external aim intent unavailable
external obstruction query unavailable
external body attachment transform unavailable
external fire backend not responding to readiness request
```

Expected response:

```text
use last valid input if safe
fall back to stable pose
mark dependency failure
avoid owning external system behavior here
```

```text
FWeaponInteractionFailureResult:

```

---

## Debug Requirements

Debug should show:

```text
failure class
failure reason
affected document/data id if known
affected socket/axis/contact/step
recovery target
whether recovery succeeded
whether authoring fix is required
```

---

## Final Formula

```text
Weapon interaction failure state =
  classified failure
  + affected interaction element
  + clear recovery/fallback
  + debug reason
  + no ownership of external systems.
```
